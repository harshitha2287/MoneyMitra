# MoneyMitra

AI-powered Loan Approval System built with Flask and Python.

## Features
- Loan approval prediction
- EMI calculation
- Stores loan history
- User-friendly interface
- More realistic employment/credit inputs

## How to Run
1. Install dependencies: `pip install -r requirements.txt`
2. Run: `python app.py`
3. Open browser at `http://127.0.0.1:5000`
